To make Soverign AI to work you have to have
--Ollama
--Python 3.10 >
--pyinstaller
--Soverign AI Zip

Step 1: Open Your AI Folder in PowerShell
Open your PowerShell terminal.
(cd c:/path/to/gguffile)(diff for everybody)
Navigate to the exact folder where your soverign-ai-main.gguf file is saved

Step 2: Build the Model in Ollama
Make sure the Ollama application is running in the background, then execute this command to register your model

                              ollama create sovereign-ai-main -f Modelfile
Step 3: Run and Chat With Your Model
Once the build process completes successfully, you can launch your model right from the terminal anytime with

                              ollama run sovereign-ai-main
Quick Verification Commands
Check that your model is successfully registered in Ollama:
ollama list
